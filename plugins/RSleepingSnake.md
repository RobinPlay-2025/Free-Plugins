🐍 RSleepingSnake
Плагин для Rust (uMod/Oxide)
Описание: Спавн змеи при сборе ресурсов в умеренных биомах.

📌 Описание
RSleepingSnake — лёгкий атмосферный плагин, который добавляет шанс появления спящей змеи при сборе ресурсов в умеренных биомах Rust.
При подборе ресурса (камень, металл, дерево и др.) рядом может появиться змея, которая создаёт неожиданность и повышает опасность фарма.

Плагин не создаёт лишних сущностей в сохранении и работает стабильно.

🧩 Возможности
✔️ Шанс появления змеи при сборе ресурсов
✔️ Проверка биома (можно отключить)
✔️ Настраиваемый список префабов, вызывающих срабатывание
✔️ Автоматическое удаление дубликатов префабов в конфиге
✔️ Производительность и простота установки

## ⚙️ Конфигурация
Конфигурационный файл создается автоматически по пути `oxide/config/RSleepingSnake.json` (если Carbon, то: `carbon/config/RSleepingSnake.json`:
```json
{
  "Вероятность спавна змеи (0.0 - 1.0)": 0.05,
  "Требовать умеренный биом": true,
  "Префабы ресурсов, при сборе которых может появиться змея": [
    "wood-collectable",
    "sulfur-collectable",
    "metal-collectable",
    "stone-collectable"
  ]
}
