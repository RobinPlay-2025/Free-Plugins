# История обновлений — RSurvivalStore

[Описание](./RSurvivalStore.md) | **История обновлений**

🛒 Обновление RSurvivalStore v2.9.7
Отказ от фоновых картинок: Меню корзины полностью переведено на стандартный интерфейс Oxide без использования тяжелых фоновых изображений.
Гибкая настройка: Все позиции, размеры, отступы и цвета панелей вынесены в конфигурацию.
Иконки по URL: Иконка корзины на экране (HUD) и подложка для чертежей теперь настраиваются через ссылки на изображения.
Увеличены иконки предметов: Изображения предметов в ячейках корзины стали крупнее.
Исправлено наложение текста: Статусы («ВЗЯТО», «НУЖНО СЛОТОВ», таймеры) теперь отображаются по центру карточки и не перекрывают название предмета.
Исправлен статус пустой корзины: Надпись «Ваша корзина пуста.» теперь появляется сразу после забора последнего предмета.
