# Spawns

## 🎯 Описание

Плагин для создания и управления наборами точек спавна. Позволяет администраторам создавать коллекции точек спавна, которые могут использоваться другими плагинами для телепортации, спавна NPC и событий.

### ✨ Ключевые особенности

- ✅ **Автоматическая установка через Tesla Coil** — установите катушку тесла, точка спавна добавится автоматически, катушка исчезнет
- ✅ **Визуальная индикация** — видите все точки спавна с номерами в игре
- ✅ **Редактирование наборов** — открывайте и изменяйте существующие наборы
- ✅ **API для плагинов** — другие плагины могут использовать ваши наборы точек

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/spawns` | Показать список всех команд |
| `/spawns new` | Начать создание нового набора точек спавна |
| `/spawns open <имя_файла>` | Открыть существующий набор для редактирования |
| `/spawns add` | Добавить точку спавна на текущей позиции |
| `/spawns remove <номер>` | Удалить точку спавна по номеру |
| `/spawns save <имя_файла>` | Сохранить текущий набор точек спавна |
| `/spawns close` | Закрыть набор без сохранения |
| `/spawns show [время]` | Показать визуальные маркеры на всех точках (время в секундах) |

## 🚀 Быстрый старт

### Создание набора через Tesla Coil (рекомендуется)

1. **Начните создание:**
   ```
   /spawns new
   ```

2. **Установите катушки тесла:**
   - Установите катушку тесла в нужном месте
   - Точка спавна добавится автоматически
   - Катушка исчезнет через 0.1 секунды
   - В чате появится: "Добавлен спавн №X"

3. **Повторите для всех точек:**
   - Установите столько катушек, сколько нужно точек
   - Каждая катушка автоматически добавляет новую точку

4. **Сохраните набор:**
   ```
   /spawns save <имя_файла>
   ```

### Альтернативный способ (вручную)

```
/spawns new
/spawns add          # Добавить точку на текущей позиции
/spawns show         # Просмотреть все точки
/spawns save my_spawns
```

## 🔧 API для разработчиков

```csharp
// Получить количество точек
int count = (int)Interface.Call("GetSpawnsCount", "my_spawns");

// Получить случайную точку
Vector3 spawn = (Vector3)Interface.Call("GetRandomSpawn", "my_spawns");

// Получить точку по номеру
Vector3 spawn = (Vector3)Interface.Call("GetSpawn", "my_spawns", 3);

// Получить все имена файлов
string[] files = (string[])Interface.Call("GetSpawnfileNames");
```
