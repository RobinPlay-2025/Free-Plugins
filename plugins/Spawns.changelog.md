# История обновлений — Spawns

[Описание](./Spawns.md) | [История обновлений](./Spawns.changelog.md)

🔄 ОБНОВЛЕНИЕ: Spawns v2.0.39 - Умное управление данными при вайпе! 🎯

✨ Что нового в версии 2.0.39:

🔧 Автоматическое удаление данных при вайпе карты
• При вайпе сервера все файлы спавнов из папки SpawnsDatabase автоматически удаляются
• Больше не нужно вручную чистить старые данные после вайпа
• Полная очистка всех файлов спавнов (alliance.json, horde.json, outcast.json и другие)

⚙️ Новая настройка в конфиге
• Добавлена опция "Удалять данные при вайпе карты" (true/false)
• Теперь вы полностью контролируете, нужно ли удалять данные при вайпе
• По умолчанию: true (данные удаляются автоматически)

💡 Зачем это нужно?
• Если карта меняется - данные автоматически очищаются (true)
• Если карта остается той же - спавны сохраняются (false)
• Гибкое управление под ваши нужды!

🎯 Как это работает:
• При вайпе карты плагин проверяет настройку в конфиге
• Если включено (true) - все файлы спавнов удаляются
• Если выключено (false) - данные сохраняются для повторного использования
• В консоли выводится сообщение о статусе удаления

📋 Что удаляется:
• Все файлы из папки SpawnsDatabase
• Метаданные (spawns_data.json) перезаписываются заново

🔧 Настройка:
Откройте конфиг плагина и найдите:
"Удалять данные при вайпе карты": true

Измените на false, если хотите сохранить спавны при вайпе:
"Удалять данные при вайпе карты": false

📌 Важно:
• Настройка применяется автоматически при следующем вайпе
• Рекомендуется использовать true при смене карты
• Используйте false, если карта остается прежней
