# RSurvivalStore

**RSurvivalStore** — это мощный плагин-клиент для игры Rust, разработанный командой RustInnovate. Он позволяет игрокам легко получать предметы, купленные в вашем веб-магазине, прямо внутри игры с помощью красивого графического интерфейса.

## Особенности плагина

* **Интеграция с веб-магазином:** Работает по API с сервером магазина. Игроки могут покупать предметы на сайте, и они автоматически появляются у них в корзине в игре.
* **HUD Иконка корзины:** Удобная иконка на экране игрока для быстрого открытия магазина.
* **Система ограничений:** Запрет открытия магазина во время рейдблока, комбатблока и в зоне чужого шкафа (с поддержкой плагинов от SkyPlugins и Umod NoEscape).
* **Addon Mode (Интеграция с меню сервера):** Может работать как самостоятельное окно или встраиваться в качестве вкладки в другие UI плагины (например, `RServerMenu`), скрывая лишние элементы и идеально вписываясь в интерфейс.
* **Кастомный UI:** Полностью настраиваемый дизайн на базе изображений. Поддержка кастомных картинок для каждого состояния (успех, блокировка, нехватка места).
* **Система умной выдачи (Take All):** Кнопка "Забрать всё" с последовательной микро-очередью, которая защищает базу данных сайта от перегрузок и исключает возможность дюпа предметов.
* **Поддержка частичных стаков:** Если в корзине куплено сразу 10 печек, игрок может забрать только одну — плагин корректно обновит число оставшихся в корзине, не удаляя слот.
* **WipeBlock:** Поддержка блокировки выдачи мощных предметов в первые дни после вайпа.

## Команды

### Игровые команды (Чат)
* `store` — открывает графический интерфейс корзины покупок (если плагин не интегрирован в RServerMenu).

### Технические (Скрытые) консольные команды
* `rsurvivalstore.take <slotId> <itemId>` — выдает конкретный предмет из корзины.
* `rsurvivalstore.takeall` — запускает очередь последовательной выдачи всех предметов из корзины (по одному каждые 0.5 сек для защиты от дюпа).

### Админские консольные команды (RCON)
* `rsurvivalstore.setup <SiteID> <SiteKey>` — первичная привязка сервера к вашему магазину. Сохраняет токены в конфигурацию.

## Настройка (Configuration)

Конфигурация плагина сохраняется в `oxide/config/RSurvivalStore.json`.

* **SiteID & SiteKey:** Ваши уникальные идентификаторы для подключения к серверу магазина. Не передавайте их третьим лицам!
* **WipeBlocks:** Список для настройки вайп-блока. Формат:
  ```json
  "Настройка блокировки товаров после вайпа": [
    {
      "Имя предмета (опционально)": "Миниган",
      "ID товара (ОБЯЗАТЕЛЬНО)": "672163dc7157ee89b09bf158",
      "Время блокировки (в часах) (ОБЯЗАТЕЛЬНО)": 72.0
    }
  ]
  ```
  Предметы из этого списка нельзя будет забрать из корзины до истечения указанного количества часов после вайпа.
* **Design (Дизайн):** Полная кастомизация интерфейса. Вы можете менять размеры (Width/Height), смещения (OffsetX/OffsetY) и названия картинок (ImageName) для:
  * Фона корзины и заголовка
  * Слотов для обычных предметов и чертежей
  * Иконок успеха, вайпблока и нехватки места
  * Кнопки "Забрать всё" и HUD-Иконки корзины

## Изображения

Плагин требует наличия изображений в папке:
`oxide/data/RSystem/RSurvivalStore/Images/`

Имена файлов в этой папке должны в точности совпадать с параметром `ImageName` в конфигурации. Плагин автоматически подгружает их в память при старте сервера, чтобы интерфейс загружался у игроков мгновенно без зависаний.

## API для разработчиков (Hooks)

Плагин предоставляет хуки для интеграции с другими плагинами (например, глобальными меню сервера):

* `void OpenAddonUI(BasePlayer player, string parentUI)`
  Открывает корзину RSurvivalStore, встраивая её внутрь указанного элемента `parentUI` без основного фона плагина.
* `void CloseAddonUI(BasePlayer player)`
  Закрывает встроенный UI корзины.
* `bool GetAddonUIStatus(ulong userId)`
  Возвращает `true`, если корзина в данный момент открыта в режиме аддона для указанного игрока.

## Уведомления об ошибках в UI

Плагин использует систему визуальных оверлеев вместо спама в чат:
* **Красная иконка с таймером:** Срабатывает WipeBlock.
* **Красная иконка "Нужно X слотов":** В инвентаре нет места для предмета.
* **Зеленая галочка:** Предмет успешно выдан.
