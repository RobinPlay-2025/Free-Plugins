# История обновлений — ZoneDomes

## История изменений (от оригинала uMod)

Данная версия плагина была полностью переработана и автоматизирована для удобной работы с ZoneManager.

### 🔄 Полная автоматизация

- ✅ **Автоматическое создание куполов** — при старте сервера все зоны из ZoneManager получают купола и маркеры на карте автоматически
- ✅ **Автозаполнение конфига** — при первом запуске, если конфиг пуст, автоматически заполняется всеми зонами из ZoneManager
- ✅ **Радиус всегда из ZoneManager** — радиус зоны всегда берётся из ZoneManager, нет дублирования настроек
- ✅ **Название зоны автоматически** — имя зоны подтягивается из ZoneManager в конфиг

### 🗺️ Отображение на карте G

- ✅ **Круговые маркеры на карте** — зоны отображаются на карте G (клавиша G) цветными кругами
- ✅ **Синхронизация цвета** — цвет маркера на карте совпадает с цветом купола в игре
- ✅ **Настраиваемая прозрачность** — можно настроить прозрачность кругов на карте через конфиг

### ⚙️ Упрощённая настройка

- ✅ **Русские ключи в конфиге** — все настройки на русском языке для удобства
- ✅ **Только необходимые параметры** — в конфиге остались только цвет типа и флаги отображения
- ✅ **Глобальные флаги** — можно включить/выключить отображение куполов и маркеров на карте глобально
- ✅ **Убрана версия из конфига** — версия плагина не сохраняется в конфиге
- ✅ **Нет файлов данных** — всё хранится в конфиге, файл `zonedomes_data.json` больше не используется

### 🚫 Удалено для автоматизации

- ❌ **Команды чата** — все команды (`/zd add`, `/zd remove`, `/zd list`) удалены
- ❌ **Локализация** — система переводов удалена (команды не нужны)
- ❌ **Права доступа** — регистрация прав удалена
- ❌ **Параметр "Слои"** — убрана настройка количества слоёв купола (всегда один купол)
- ❌ **API методы** — удалены публичные API методы для других плагинов
- ❌ **Таймеры** — убрана периодическая проверка новых зон (работает только при старте/перезагрузке)
