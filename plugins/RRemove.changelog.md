# История обновлений — RRemove

[Описание](./RRemove.md) | **История обновлений**

Исправление работы плагина на Oxide.
🔨 RRemove 2.0.0 — апгрейд всего здания одним ударом и откат улучшений
Большое обновление режима апгрейда: постройка теперь поднимается до выбранного материала целиком одним ударом киянки — с выбранным скином и цветом, а при желании можно и откатывать улучшения назад с возвратом части ресурсов.

✨ Апгрейд всего здания
Раньше режим апгрейда поднимал только задетый блок. Теперь после выбора материала открывается подменю:

Один блок — как раньше, апгрейд только задетого блока;
Всё здание — удар по любому блоку строения, и вся постройка (всё, что связано в одно строение) станет выбранным материалом со скином. Идеально для быстрой сборки «черновика» из твиня: поставил макет → ударил → готовый дом.
Скины построек (DLC) и палитра цветов (колесо баллончика для контейнерных скинов) работают так же, как раньше — выбор скина клавишами Q/E прямо в главном меню, применяется и к одному блоку, и ко всему зданию.

Условия: авторизация в шкафу строения; в рейд/комбат-блоке функция недоступна (настраивается).

🎮 Как пользоваться (игрокам)
Откройте радиальное меню (X / F или бинд rremove.menu).
Выберите материал: Дерево / Камень / Металл / МВК — скин листается клавишами Q/E.
В подменю выберите «Всё здание» или «Один блок».
Бейте киянкой. Строить планом с активным режимом тоже можно — новый блок сразу поднимется до выбранного материала.
⏪ Откат улучшений (по желанию сервера)
Материал ниже текущего (например, камень → дерево) по умолчанию запрещён — как в ванили.
Владелец сервера может разрешить откат: он бесплатный, а игроку возвращается часть ресурсов — 25% от стоимости текущей марки блока по умолчанию (процент настраивается, 0 — без возврата).
В массовом режиме смешанная база нормализуется к цели: повышения оплачиваются, понижения — с возвратом.
💰 Затраты ресурсов
Апгрейд списывает ванильную стоимость материалов (как обычный апгрейд киянкой); перескин той же марки дешевле — 20%, как в игре.
Блоки, на которые не хватило ресурсов, пропускаются — в конце показывается, сколько пропущено. Если не хватило ни на один блок — одно понятное сообщение.
Бесплатный апгрейд — только с правом rremove.nocost.
🔐 Права (для владельцев серверов)
Право	Доступ
rremove.use	режимы удаления
rremove.admin	админские режимы удаления
rremove.upgrade	апгрейд одного блока
rremove.wholeupgrade	НОВОЕ — апгрейд всего здания
rremove.nocost	апгрейд без затрат ресурсов
rremove.skinsfree	скины построек без владения DLC

text
oxide.grant group vip rremove.wholeupgrade
oxide.grant group admin rremove.nocost

Конфиг и lang-файлы мигрируют автоматически — просто обновите плагин: новые ключи появятся, устаревшие исчезнут из файла при первом запуске. Удалять конфиг не нужно.

🛠 Исправления
Устранено предупреждение Oxide «Duplicate permission registered 'rremove.upgrade'» — привилегия массового апгрейда вынесена в отдельное право.
Исправлен редкий NRE при применении цвета палитры к блоку, у которого пара (материал, скин) отсутствует.
Если ресурсов не хватило ни на один блок — одно понятное сообщение вместо «завершён: 0 блок(ов)».
Одиночный апгрейд больше не списывает полную стоимость материала при понижении марки (раньше камень → дерево списывало дерево).
🚀 Производительность
Апгрейд всего здания выполняется пакетами (20 блоков за тик по умолчанию, интервал и размер настраиваются) — даже большие базы поднимаются плавно, без просадок FPS на сервере.
