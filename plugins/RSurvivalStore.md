# RSurvivalStore

**RSurvivalStore** — современный и оптимизированный плагин-клиент внутриигровой корзины для серверов Rust, интегрированный с платформой **SurvivalShop**. Позволяет игрокам моментально получать купленные в веб-магазине товары и наборы прямо в игре через удобный и гибкий интерфейс.

---

## 🚀 Особенности плагина

* **Интеграция с SurvivalShop API:** Прямая синхронизация с сайтом магазина. При покупке товары моментально становятся доступны в игре.
* **Векторный CUI без фоновых картинок:** Интерфейс выполнен полностью на нативных элементах Oxide CUI, не требует тяжелых текстур и идеально сочетается с общим дизайном серверных меню.
* **Иконки по URL с авто-кэшированием:** Иконка кнопки корзины (HUD) и подложка для чертежей загружаются по ссылкам и автоматически кэшируются на сервере (`oxide/data/RSystem/RSurvivalStore/ImageCache/`).
* **Крупные карточки и умные оверлеи:** Увеличенные иконки товаров, поддержка фона для чертежей и аккуратные центрированные плашки статусов («ВЗЯТО», «НУЖНО СЛОТОВ», таймеры вайп-блока).
* **Система умной выдачи (Take All):** Кнопка «Забрать всё» с последовательной микро-очередью, исключающая перегрузку сайта и защищающая от дюпа предметов.
* **Поддержка частичных стаков:** Если в слоте корзины несколько предметов, игрок может забирать их частями.
* **WipeBlock:** Гибкая настройка блокировки выдачи топовых предметов в первые часы/дни после вайпа сервера.
* **Система ограничений:** Запрет открытия корзины во время рейд-блока, комбат-блока и в зоне чужого шкафа (с поддержкой NoEscape и плагинов блокировок).
* **Поддержка встроенного режима (Addon / Embed Mode):** Возможность интеграции в качестве вкладки в другие панели и глобальные меню сервера (`RServerMenu` и др.).
* **Полная локализация:** Все текстовые сообщения и заголовок кнопки «ЗАБРАТЬ ВСЁ» переведены в стандартную систему локализации Oxide (`oxide/lang/`).

## 🎮 Команды

### Игровые команды (Чат)
* `/store` — открывает графический интерфейс корзины покупок.

### Администраторские консольные команды (RCON)
* `rsurvivalstore.setup <SiteID> <SiteKey>` — первичная привязка сервера к вашему магазину на SurvivalShop (сохраняет ключи в конфиг и запускает регистрацию).

### Технические команды UI
* `rsurvivalstore.take <slotId> <itemId>` — запрос на получение конкретного предмета из корзины.
* `rsurvivalstore.takeall` — запуск очереди автоматического забора всех предметов из корзины.

## 🔌 API для разработчиков (Hooks)

Плагин предоставляет методы для встраивания в сторонние меню:

* `void OpenAddonUI(BasePlayer player, string parentUI)` / `DrawEmbedUI` — открывает корзину внутри родительского контейнера `parentUI`.
* `void CloseAddonUI(BasePlayer player)` / `CloseEmbedUI` — закрывает встроенный UI корзины.
* `bool GetAddonUIStatus(ulong userId)` — возвращает `true`, если у игрока открыта встроенная корзина.
