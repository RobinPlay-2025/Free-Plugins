## v1.0.4 — Auto Shortname Detection & `ric add2`

### Added
- Поддержка Steam API (`GetPublishedFileDetails/v1/`) для автоматического определения шортнеймов предметов.
- Новое поле в конфигурации: `SteamApiKey` (класс `ConfigData`).
- Словарь `_workshopNameToShortname` для сопоставления тегов Workshop → shortname.
- Консольная команда (только серверная):  
ric add2 <skinId1> <skinId2> ... (до 15 штук)
Возможности:
- Обработка до 15 ID скинов за один вызов.
- Получение информации о скинах через Steam API.
- Автоматическое определение shortname по тегам.
- Добавление в `BlockedSkins` и автоматическое сохранение конфигурации.
- Вывод количества успешно добавленных записей.

### Improved
- Добавлены модели для десериализации ответа Steam:
- `PublishedFileDetails`
- `SkinsResponse`
- `SkinsQueryResponse`
- Улучшена нормализация тегов и алгоритм сопоставления.
- Исправлены все предупреждения линтера и проведена общая чистка кода.
